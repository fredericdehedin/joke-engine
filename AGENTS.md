# Agent Instructions

## Git workflow

- Use semantic commit messages: prefix the summary with a type such as
  `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`, or `tweak:`,
  followed by a short imperative description (e.g. `feat: add dark/crude
  comedian rewrite prompt`).
- Keep each commit focused on one logical change; split unrelated changes
  into separate commits.
